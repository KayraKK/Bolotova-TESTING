# Bolotova-TESTING
лабы по тестированию

## Болотова ЕС
## 2307б1

### Описание проекта
Программа для определения вида треугольника по длинам сторон и вычисления координат его вершин для отрисовки в поле 100×100 px.

### Функционал:
Валидация входных данных (3 строки с вещественными числами)
Определение типа треугольника: равносторонний, равнобедренный, разносторонний, не треугольник
Расчёт координат вершин, масштабированных под 100×100 px
Логирование успешных и неуспешных запросов в файл и консоль
